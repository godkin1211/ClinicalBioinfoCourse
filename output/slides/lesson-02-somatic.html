基因檢測是補充資訊，不是取代病理、影像或臨床判斷。

理解這一頁｜例：兩份病理診斷相同的腫瘤，可能只有其中一份帶有特定 EGFR 變異。病理回答「是哪一類」，分子檢測補問「有哪些改變」。

LESSON 02 / 檢測邊界

先分清楚：這次檢測要回答哪一種問題？

問題需要的資訊不能直接推論
腫瘤有哪些分子改變？腫瘤 DNA／RNA 或其他標記所有變異都與癌症有關
是否帶有遺傳性癌症風險？合適的生殖系檢測與確認流程腫瘤檢出就等於遺傳

理解這一頁｜例：腫瘤中測到某個變異，只能先說「這份腫瘤檢體有此訊號」；若要回答是否為遺傳性變異，需要另一層來源確認。

LESSON 02 / 實務 · 選方法

先問要找什麼，再選 panel、WES 或 WGS

方法適合的問題／優勢必須確認
Targeted panel集中在選定基因／區域，常可分配較高深度基因清單、熱點或全外顯子？支援哪些事件？
WES · 外顯子定序較廣泛探索蛋白編碼區變異捕獲不均；非編碼區與部分 SV 有限制
WGS · 全基因體定序廣泛位置與結構變異證據成本／資料量／深度與低頻偵測的取捨

需要 RNA 融合或蛋白表現資訊時，可能須搭配 RNA 或其他檢測。

理解這一頁｜例：固定讀段預算下，把讀段集中在較小範圍，通常能取得較高深度；把範圍擴到全基因體，則要重新評估低頻事件的偵測能力。

不存在對所有問題都最好的平台；範圍、事件類型及偵測能力須依方法驗證。

LESSON 02 / 來源概念

腫瘤檢出，不等於只存在於腫瘤

Germline · 生殖系

源於生殖細胞／受精卵的變異
通常存在於多數體細胞

Somatic · 體細胞

生命歷程中後來產生的變異
可能僅存在部分組織或細胞

腫瘤檢體
→
Germline ＋ somatic ＋ 技術錯誤
→
仍需區分來源

判斷來源需要對照與證據；不能只看腫瘤中是否出現某個變異。

理解這一頁｜例：個案原本就有的生殖系變異，也會出現在腫瘤 DNA 裡。因此「出現在腫瘤 VCF」不等於「癌細胞後來才產生」。

腫瘤純度、局部拷貝數、嵌合與抽樣都能改變觀察比例。GATK：Mutect2

Tumor–normal 與 tumor-only 差在哪？

設計多了什麼資訊？仍缺什麼？
Tumor–normal
腫瘤＋同人正常		比較個案本人的 allele 證據
協助區分 germline／somatic		正常仍可能低覆蓋、污染

LESSON 02 / 檢體 · 採樣與保存

採樣當下，就決定資料代表哪一個腫瘤

收集與處理紀錄為什麼影響分析？
哪個病灶？哪個時間？治療前或後？不同區域與時間可能有不同變異組成
固定／冷凍、處理延遲、保存與凍融改變核酸完整度與損傷背景
組織／血漿／正常對照與身分追蹤決定訊號來源、配對與污染檢查

生物資訊可以發現異常，但無法把沒有採到的腫瘤細胞算回來。

理解這一頁｜例：治療前原發病灶與治療後轉移病灶的差異，可能同時包含時間與部位效應；缺少採樣紀錄，就不能只解釋為治療造成。

LESSON 02 / 製備 · 核酸萃取

有 DNA，不代表有足夠可分析的 DNA

量是否足夠？

用適當方法評估濃度與輸入量；

品質是否適用？

檢查片段長度、完整度，
必要時評估可擴增性。

交給分析端的資訊後續可能看到的影響
低輸入量／高 PCR 需求重複率較高、有效分子深度不足

LESSON 02 / 分子證據

400 條 reads，不一定來自 400 個分子

假設：重複讀取

20 × 20

20 個原始分子
每個產生 20 條 reads

假設：獨立取樣

400 × 1

400 個原始分子
每個產生 1 條 read

兩者 raw depth 都是 400；獨立分子數不同。UMI 可協助分組與 consensus。

理解這一頁｜例：20 個原始分子各複製 20 次，與 400 個分子各讀一次，都是 400 reads。前者的低頻判斷，可能被其中一個原始分子強烈影響。

UMI＝unique molecular identifier，分子識別標記。算例非本課 BAM 分子真值；UMI 不解決所有損傷或比對錯誤。fgbio：consensus reads

LESSON 02 / 下機 QC · FastQC 判讀

FastQC：先看圖形，再解讀警示

① 各位置鹼基品質

Per base sequence quality

橫軸 read 位置；縱軸 Q，留意末端下降。
Q20 ≈ 1%、Q30 ≈ 0.1% 鹼基錯誤機率。
這是鹼基品質，不是變異可信度。

② 接頭含量

Adapter Content

橫軸 read 位置；縱軸累積含接頭比例。
末端上升，可能讀穿較短的 DNA 片段。
回查實際接頭序列與片段長度。

③ 每條 read 的 GC 分布

Per sequence GC content

橫軸 GC%；縱軸 read 數，留意尖峰／多峰。
先對照 panel 與文庫設計，再看分布偏移。
偏離模型，不等於已證實污染。

④ 序列重複程度

Sequence Duplication Levels

橫軸序列出現次數，留意高重複區偏多。
可能來自 PCR，也可能是靶向富集。
不等於獨立分子數或 BAM 去重率。

理解這一頁｜燈號是模組警示，不是樣本合格率。例：R2 末端 Q 下降且接頭上升，先查片段與接頭，對照 R1／同批樣本；處理後重查資料保留量，不以全綠為目標。

LESSON 02 / 下機 QC · 比對與覆蓋

平均 500×，不代表每個目標位置都有 500×

指標回答的問題
Mapping／MAPQ、insert size讀段能否可靠定位？片段分布是否異常？
Duplicates／UMI 分子深度是否反覆讀同一分子？有多少有效證據？
On-target、coverage breadth、均勻度讀到目標了嗎？多少目標達到要求的深度？
身分 fingerprint／污染估計配對是否合理？有無其他來源混入？

看逐區域覆蓋與方法規格；平均深度不能替代可評估範圍。

理解這一頁｜算例：4 個位置深度為 1000、900、100、0，平均仍是 500×；但以 100× 為示意門檻，只有 3/4 位置達標，最後一個完全沒讀到。

Capture、amplicon、WGS 使用適合的指標；不同 filtering 定義的數字不可直接比較。Picard：QC metrics

LESSON 02 / QC · 回饋迴路

QC 的用途，是決定下一步，而不只是打勾

觀察到的問題回查什麼？團隊可評估的下一步
讀段少、文庫仍有複雜度上機分配與資料產出是否補定序
高重複、獨立分子不足輸入量與文庫製備重製文庫／另取檢體的可行性
配對疑似錯誤或污染追蹤鏈、正常來源及批次暫停結果釋出、查明來源

先保留 QC 證據與原因；加深定序不一定能解決前分析問題。

理解這一頁｜例：文庫還有許多未充分讀取的分子，補定序可能增加證據；若早已反覆讀同一批少量分子，再加 reads 的效益可能很小。

此為排查框架，非自動決策規則；依方法驗證與院內 SOP，由責任人員審核。

LESSON 02 / 附錄 B · VCF

bcftools view -Oz -o candidates.vcf.gz candidates.vcf

LESSON 02 / 附錄 · 混合模型

把 VAF 的四個影響因素分開

預期 VAF = p × f × m / [p × C + (1 − p) × 2]
符號意思分子／分母的角色
p模型中的腫瘤細胞比例（purity）腫瘤對混合物的貢獻
fCCF：帶變異的癌細胞比例多少癌細胞提供 ALT
m帶變異癌細胞內的 ALT 拷貝數每個帶變異癌細胞提供幾份 ALT
C此區域每個癌細胞的總拷貝數腫瘤＋正常的總 allele 貢獻

理解這一頁｜用 100 個細胞想：p=0.6 表示 60 個癌細胞；若 f=0.5、m=1，只有 30 份 ALT。每個細胞總 CN=2 時，分母是 200，VAF=15%。

假設正常二倍體且無 ALT，所有癌細胞此處 CN 一致、allele 等機率取樣。不是通用 CCF 反推公式。

LESSON 02 / 附錄 · Copy number

總拷貝數增加，VAF 不一定上升

固定 p=20%、f=100%、腫瘤總 CN=6；只改變 ALT 有幾份。

1 份 ALT ＋ 5 份 REF

7.14%
0.2 × 1 / 2.8

3 份 ALT ＋ 3 份 REF

21.43%
0.2 × 3 / 2.8

除了總 CN，還要知道哪一個 allele 被增加，以及增加幾份。

理解這一頁｜兩種情境的分母都是 2.8；但每個混合細胞提供的 ALT 分別是 0.2 與 0.6，所以比例是 7.14% 與 21.43%。關鍵是增加哪個 allele。

1.138

LESSON 02 / 附錄 C · 抽樣模型

多讀一些，比較容易抽到 ALT，但不等於 LOD

假設 reads 獨立、真實 ALT 機率 5%、完全沒有錯誤。

讀段數 n至少看到 3 條 ALT 的理論機率
3018.78%
10088.17%
400接近 100%（不是數學上保證）
X ~ Binomial(n, 0.05)；P(X ≥ 3) = 1 − P(X ≤ 2)

系統性錯誤、PCR 重複與 caller 規則不在此模型內；不能直接當 sensitivity 或 LOD。

理解這一頁｜在無錯誤、獨立抽樣模型下，30 reads 至少見 3 條 ALT 的機率約 18.8%；但真實流程還要能把 ALT 與錯誤區分，不能把此機率直接叫 sensitivity。

LOD＝偵測極限，需適當材料與重複實驗驗證。程式四捨五入顯示 1.000000 不代表機率等於 1。

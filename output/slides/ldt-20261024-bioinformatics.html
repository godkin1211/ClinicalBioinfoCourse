LDTs / 01 · 先從問題出發

兩份報告都寫 5%：你會一樣相信嗎？

同樣的數字

兩個候選位點都有 400 條納入計算的 reads，其中 20 條支持 ALT，因此都是 5% VAF。

不同的證據

A 的支持分布較分散；B 的支持都來自同一方向、集中在讀段末端。還能直接當作同等可信嗎？

Read 是一次讀出的短序列；ALT 是相對參考序列的替代形式。VAF（變異等位基因頻率）是支持 ALT 的讀段比例，不是「真實的機率」。

生物資訊的工作不是把數字算出來，而是保留「為什麼可以相信它」的證據。

LDTs / 02 · 技術選擇

Array、Panel、WES、WGS：涵蓋更多，不等於每處都更可靠

平台怎麼量測對結果的主要限制
SNP array用探針量測預設位點的等位基因訊號可看基因型／部分 CNV；不是全面找新序列變異
Targeted panel集中定序選定基因或區域可聚焦深度；目標以外通常不能評估
WES 全外顯子捕捉並定序設計中的外顯子等區域捕捉不均；不是每個 exon 都有足夠覆蓋
WGS 全基因體較廣地讀取基因體序列重複區仍困難；各類事件仍需專用方法

選擇依預期用途與已驗證能力；RNA-seq 則回答表現、剪接或部分融合等不同問題。

LDTs / 02 · 檔案不是附件而已

FASTQ → BAM／CRAM → VCF：每一步留下不同證據

檔案內容與用途不能把它當成什麼
FASTQ每條 read 的序列與逐鹼基品質尚未告訴你位於哪個基因
BAM／CRAM比對位置、方向、配對、序列與品質比對成功不代表位置一定正確
VCF候選變異、樣本欄位、品質與 FILTER沒有一列不等於那個位置是正常
FASTA／BED／GTF參考序列／目標區間／基因與轉錄本註解這些是分析依據，不是病人實測資料

結果表方便閱讀，卻不能取代原始讀段、比對證據、QC 與流程紀錄。

LDTs / 02 · 容易忽略的錯誤

資料內容沒壞，也可能配錯人、用錯地圖

身分核對：檔案屬於誰？

串接個案、檢體、文庫及定序 ID；核對 tumor–normal 配對。SNP fingerprint 是多個基因型特徵的比對，不靠單一 SNP 判斷。

版本核對：座標代表哪裡？

GRCh37 與 GRCh38 不可直接混用；FASTA、目標 BED、GTF 與註解版本應相容。改掉檔名不會轉換座標。

Checksum（校驗碼）可檢查傳輸前後檔案是否一致，但無法證明採檢時沒有配錯病人。

先確認身分與座標，再看漂亮的品質分數；否則可能精確地分析了錯誤的資料。

LDTs / 03 · 看圖練習

FastQC：先看座標與分布，不要只看 PASS／FAIL

這張圖怎麼看？

橫軸是 read 內的位置；縱軸 Q 越高，估計的鹼基錯誤率越低。

箱體：25–75 百分位；紅線：中位數；藍線：平均值。

末端下降時，核對接頭、讀長與保留量，再評估修剪。這不是臨床放行標準。

Q30 約對應 0.1% 的單鹼基判讀錯誤率，不代表「這個變異 99.9% 真實」。

LDTs / 03 · 獨立證據

400 reads，可能只是 20 個原始分子被重複讀取

為什麼會放大錯誤？

PCR（聚合酶連鎖反應）擴增 DNA 時，也可能複製原始分子上的錯誤。

左例每個分子等量擴增：一個錯誤分子就能貢獻 5% reads。

UMI 用分子標記追蹤讀段家族；但不能自動修正所有早期損傷或比對錯誤。

重複讀取增加的是讀段數，不一定增加獨立分子；UMI 不是萬能除錯器。

比對、判定、篩選、註解：四個步驟回答不同問題

步驟白話問題需要避免的誤解
Alignment 比對這條 read 最可能來自哪個位置？對得上不等於唯一、正確地定位
Calling 候選判定差異較像真實變異，還是背景錯誤？不是只計算 ALT 是否超過固定比例
Filtering 篩選哪些候選有污染、偏差或低品質疑慮？刪除所有失敗列會遺失稽核理由
Annotation 註解對應哪個基因、轉錄本與已知資料？資料庫有收錄不會讓錯誤讀段變真

先有可靠的測量證據，再討論生物意義；流程跑完不是品質驗證完成。

LDTs / 04 · 腫瘤分析的背景

Tumor-only 不是「只把 normal 那一步省掉」

Tumor–normal：同一人的配對比較

正常檢體提供個體原有變異的證據，協助區分 germline 與腫瘤特有訊號；仍須核對來源、深度及污染。

Tumor-only：留下更多來源不確定性

可用族群頻率、技術背景及模型篩選，但不能可靠排除所有 germline。資料庫沒收錄不等於 somatic。

Germline 與 somatic 描述變異的來源；50% 與 5% 則是觀察比例，不能直接互相對號入座。

正常檢體也要選對：血液腫瘤或克隆性造血時，血液不一定是理想 normal。

VAF 是 allele 的讀取比例，不是癌細胞百分比

這裡的腫瘤含量是 10%

每個細胞有兩份該位置的 DNA。腫瘤細胞只帶一份 ALT，因此 ALT 占 1/20。

雖然 VAF 是 5%，這個例子中所有腫瘤細胞都帶有變異。

真實結果還受 CN、亞克隆與比對偏差影響，不能直接反推純度。

低 VAF 可以是低腫瘤含量，也可以有其他解釋；不可只看一個比例判斷克隆性。

LDTs / 04 · 不同變異需要不同證據

SNV、CNV、SV：不能用同一個分數保證全部

事件核心證據常見影響因素
SNV／短 indel鹼基替換、短插入缺失；局部序列與讀段支持品質、比對、背景錯誤與低 VAF

例如區域讀段變多，可能是 DNA 拷貝增加，也可能只是捕捉效率較高；先校正，再建模。

不同事件類型須分別評估檢測能力；「SNV 驗證通過」不代表 CNV／融合也通過。

LDTs / 05 · RNA 增加了哪種資訊

DNA 問序列；RNA 還能問「表現多少、如何接合」

Exon 與 junction 是什麼？

Exon 是成熟 RNA 保留的區段；junction 是區段接合的位置。

Alternative splicing 讓同一基因產生不同 RNA 形式，總量不變也可能換了形式。

跨 E1–E3 的讀段支持局部跳躍；不直接證明 DNA 刪掉 E2。

只有 gene count matrix，通常無法還原已丟失的接合位置；剪接要保留相應證據。

LDTs / 05 · RNA 的分析限制

RNA-seq 的 QC、分母與研究設計都會改變答案

先確認到底量到什麼 RNA

Poly(A) 富集與 rRNA 去除取得的 RNA 母體不同；股向設定錯誤會影響歸屬。高比對率也可能主要來自 rRNA。

再區分探索與臨床檢測

Counts 是計數，TPM 是相對豐度；DESeq2 等方法不能把 TPM 直接當 raw counts。批次與細胞組成也會造成表現差異。

差異表現是比較群組；若要用於單一病人分類，必須另定模型、閾值、適用對象與獨立驗證。

「顯著基因」不是已驗證 biomarker；p 值與漂亮熱圖不能直接變成 LDT 的性能聲稱。

保留舊版本與回復方案，不在正式個案上直接試最新版。

Container 固定部分軟體環境，但不能代替資料版本、參數紀錄或效能驗證。

AMP/CAP：生物資訊流程驗證，2018 · 衛福部申請須知：115/03/1326 / 34
LDTs / 07 · 報告與限制

「未檢出」與「無法判定」，必須分開說

情境可以表達不應過度推論
目標及品質均符合規格在已驗證範圍與本檢體條件下未檢出符合規則的事件不能說此基因完全正常或排除所有疾病
關鍵區域覆蓋不足該區域無法可靠評估，依程序說明限制／補測不能因 VCF 沒有記錄就稱陰性
候選證據矛盾依規則複核、補充檢測或標示無法確定不能只因資料庫是 hotspot 就放行

可追溯報告應連回方法、範圍、限制與審核；「沒找到」與「沒能力找」不是同一件事。

LDTs / 07 · 品質紀錄與資料安全

資料交出去，責任與證據不能一起消失

最低可追溯資料包

樣本對照表、原始檔與校驗碼、QC、程式／參數／資料庫版本、篩選原因、複核及報告紀錄。保存與刪除依核准制度。

委外、雲端與 AI 都要受控

確認存取權限、傳輸／儲存保護、紀錄、備份復原及服務分工。移除姓名不代表基因資料可以任意上傳。

AI 可協助草擬程式或檢查清單；輸出仍須實際驗證，不能自行修改 QC、排除樣本或核發報告。

委外與商用軟體可以分工，不會自動取代檢測單位的品質與審核責任。

看到 5% VAF，先走完五個問題再下結論

問題本案例應回查的證據
1. 在聲稱範圍內嗎？檢體、區域、事件類型、濃度是否落在驗證範圍

LDTs / 備查 A · Array

BAF 與 LRR：比例與總訊號要一起看

觀察量白話意思判讀限制
BAF：B allele frequency校正後 B 等位基因相對訊號；典型二倍體群聚接近 0、0.5、1A／B 是平台指定的 allele 標籤，不固定代表 A/T/G/C
LRR：Log R Ratio總訊號相對參考預期值的 log₂ 比值；0 代表接近該基準上升／下降可提示拷貝增減，也受噪音與校正影響
長區段缺乏雜合可能是連續純合或其他造成 allele 不平衡的情境ROH 不等於單倍體；要合併總訊號與區域證據

Array 是訊號模型；保留強度資訊才能回查，只有 AA／AB／BB 無法還原所有證據。

LDTs / 備查 B · RNA 研究設計

疾病與批次完全重疊，軟體無法把兩者分開

設計批次 1批次 2能否分開估計疾病與批次？
完全混雜全是對照全是病例不能；觀察到的差異有兩種重疊解釋
較合理配置含病例與對照也含病例與對照有機會；仍需足夠重複及合適模型

Covariate：模型中的變數

例如年齡、批次、治療；是否放入模型需依研究設計與問題決定。

Confounding：效應難以區分

例如病例全部使用另一種建庫方式；單靠事後校正不能創造缺少的對照。

多讀同一個病人不會變成更多病人；模型與臨床分類器都需要適當的獨立驗證。

LDTs / 備查 C · 複合 biomarker

TMB、MSI、HRD：名稱相同，不代表方法可互換

指標主要在量什麼必須查核的限制
TMB 腫瘤突變負荷符合規則的體細胞變異數／可評估區域大小，常用 mut/MbPanel 範圍、germline 排除、事件規則與門檻
MSI 微衛星不穩定重複序列長度分布異常的證據標記集合、演算法、對照需求與腫瘤含量
HRD 同源重組修復缺陷可由相關基因、基因體疤痕或功能測試評估不同層面BRCA、疤痕分數、功能缺陷不是同義；各測試需分別驗證

不能將單一基因、單一分數或其他廠牌門檻，直接搬成這套 LDT 的聲稱。

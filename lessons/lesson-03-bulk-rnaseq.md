# Lesson 03 — Bulk RNA-seq：從檢體到差異表現與可變剪接

## 課程簡介

本課程以臨床研究中的基因表現比較為主軸，介紹整體轉錄體定序（Bulk RNA-seq）從檢體處理、文庫製備到差異表現分析的完整流程。內容涵蓋研究分組、生物重複與批次設計，說明 FASTQ、BAM、GTF 及基因表現計數矩陣的用途，並介紹讀段品質控制、序列比對、表現量估計、正規化與多重檢定的基本原理。同時納入可變剪接分析，認識外顯子跳躍、內含子滯留及轉錄本使用比例的差異，理解基因總表現量之外的轉錄體變化。透過資料與圖表案例，學習判讀主成分分析、火山圖及熱圖，辨識離群樣本、批次效應與混雜因素，並區分統計顯著性與表現變化幅度，建立從研究問題到結果解釋的整體概念。

## 課程目標

完成本堂後，學員能：

1. 說明基因、轉錄本、RNA 表現量及 bulk 混合訊號的差別。
2. 為臨床研究界定獨立樣本、分組／配對、批次與比較方向。
3. 理解檢體、建庫、FASTQ／BAM／GTF、比對與定量如何影響可分析的資訊。
4. 區分 counts、TPM、正規化與批次調整，並解釋差異表現的基本模型。
5. 判讀 PCA、火山圖、MA plot、熱圖、效應量及多重檢定結果。
6. 區分基因總表現與可變剪接，解釋 PSI／ΔPSI、常見事件及驗證限制。

## 學員完整版教材

[第三堂完整學員講義](lesson-03-materials.md)是本課主要教材。從基礎背景到分析原理逐節展開，含 12 章正文、程式與圖表導讀、12 題練習詳解及參考資料；不列各部分授課時長，也不要求學員先會 R 或命令列。

前兩堂從 DNA 觀察基因體差異，本堂轉向 RNA 的量與結構。貫穿案例為比較免疫治療 responder 與 non-responder 的治療前腫瘤 RNA，練習辨認批次、組織成分與臨床共變數對推論的影響；它是研究設計情境，不是本院實際分析結果。

## 核心資料流

```text
研究問題、病人層級設計與 metadata
  → RNA 萃取／文庫 → FASTQ → 讀段 QC → 比對／定量 → 樣本 QC
      ├─ gene counts → 正規化與探索 → 模型 → 差異表現
      └─ junction／exon／transcript 證據 → 剪接或使用比例分析
  → 效應幅度、不確定性、多重檢定與獨立驗證
```

## 可重跑的教學示範

[示範說明與程式](../demos/lesson-03-bulk-rnaseq/README.md)使用 3,000 個人工基因與 12 個合成樣本，展示 sample sheet、DESeq2、PCA、MA／volcano 與樣本距離圖，另外重算 PSI 算例。這不是臨床資料，也沒有執行 FASTQ 比對或正式差異剪接分析；實際執行環境與範圍附在輸出紀錄。

原有 AI-agent 少量基因合成資料仍用於 metadata 稽核，不用它展示正式 DE 推論。Pathway、GSEA 與公開資料整合的深入內容留待第四堂；本堂先學會交付完整且方向清楚的基因統計量及適當背景集合。
